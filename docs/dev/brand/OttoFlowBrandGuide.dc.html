Clear space & minimum size
  • Clear space on all sides equals half the height of the otter mark.
  • Horizontal lockup: never below 120 px wide on screen, 30 mm in print.
  • Icon alone: never below 16 px. Below 32 px, drop the whiskers by using the rounded-square icon.
  • Gap between mark and wordmark is fixed at 21% of the mark height.
Don't
  • Recolour the otter, or place it on a busy photograph.
  • Set "OttoFlow" as one colour — the two-tone split is the wordmark.
  • Stretch, rotate, or add a drop shadow to the mark.
  • Use the teal for body copy or headlines; it is a mark and accent colour only.

Relationship to the Nirmata palette

OttoFlow is a Nirmata product, so it inherits Nirmata Navy for all text and Nirmata Blue for interactive elements. The OttoFlow teal replaces Nirmata Sky as the product's accent — the two are close in hue but Sky is brighter, so pick one per surface rather than mixing them.

The wordmark

The existing logotype is set in a Helvetica-class grotesque at Regular weight, reproduced here in Arimo, which is metrically identical and open-licensed. Treat the wordmark as fixed artwork: never re-set it in Ubuntu, and never re-space it. Ubuntu is for headlines that sit next to the logo, not for the logo itself.

A note on resolution

The otter in the source file is 392 × 392 px of raster artwork — that is the ceiling on real detail. These exports resample it cleanly and hold up to about 400 px on screen or 40 mm in print. Anything larger, or any true vector use, needs the original illustration source.

The wordmark in every export is live type, so it stays crisp at any size.
